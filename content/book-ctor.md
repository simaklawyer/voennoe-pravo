# Конструктор стратегии

Модуль: book · 12.2 · strategy
Теги: стратегия

Используйте этот алгоритм при первом контакте с делом, чтобы собрать индивидуальный маршрут из готовых блоков.

## Алгоритм сборки

### 1. Идентификация клиента

- Кто он: мобилизованный / контрактник / доброволец? (От этого зависят права по Указу 580 и выплаты.)
- Где он физически: в зоне СВО / в госпитале / дома (в отпуске) / в СОЧ (скрывается)?

### 2. Точка А — что есть

Составить список документов: справка 100, справка 98, выписной эпикриз, контракт, отпускной билет, обращения, рапорты.

Если документов нет — блок «восстановление»: сначала запросы и дубликаты, только потом основная стратегия.

### 3. Точка Б — цель

Увольнение? Выплата? Лечение?

Проверка на реалистичность: если контрактник хочет уволиться «просто по окончании контракта» без льготных оснований (возраст, здоровье, социально значимые болезни) — цель недостижима без сложного пути через Указ 580.

### 4. Выбор стратегии

- увольнение по здоровью → стратегия №1;
- лечение, а часть не пускает → стратегия №6;
- выплаты за ранение → стратегия №3;
- семейные обстоятельства → стратегия №7;
- направление на ВВК из дома → стратегия №4;
- обжалование ВВК → стратегия №5;
- легализация отсутствия / защита от СОЧ → стратегия №2.

### 5. Спецконтуры (учёт рисков)

- риск уголовки (СОЧ) → контур безопасности: уведомление комендатуры, прокуратуры, заказные письма;
- спорный диагноз → контур НВВЭ / медицинский.

### 6. Запуск цикла

Действие (рапорт / жалоба) → ожидание (контроль трека) → результат (документ).

Если отказ — ветка «обжалование». Если игнор — ветка «прокуратура».

## Золотое правило

**Нет документа — нет события.**

Если клиент «сказал командиру», но не подал рапорт — юридически он ничего не говорил. Если «лечится дома», но не уведомил часть и не продлил отпуск — это потенциально СОЧ (ст. 337 УК РФ). Сначала бумажный след, потом требование результата.
