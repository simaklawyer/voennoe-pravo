# Военное право — рабочий конспект

Карманный справочник: модули курса, база знаний, семь стратегий.

## Как пользоваться

Живой сайт — ссылка из Grok (превью / опубликованное приложение). Открывается в браузере телефона за секунду.

Чтобы было как приложение: Safari или Chrome → **На экран «Домой»**. Иконка на рабочем столе, без поиска в Google.

Коллегам — та же ссылка. Локальный сервер не нужен.

Сайт закрыт от поисковой выдачи (`noindex`, `nofollow`). Это не секретный сейф: у кого есть ссылка, тот откроет.
