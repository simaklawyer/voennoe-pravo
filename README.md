# Военное право — шпаргалки (PWA)

Карманный справочник: модули, шпаргалки, быстрый поиск. Работает как приложение на телефоне (офлайн после первого открытия).

## Рекомендуемый хостинг: GitHub Pages

1. Репозиторий → **Settings → General** → сделайте **Public** (для бесплатных Pages).
2. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / folder: **/ (root)** → Save.
3. Через 1–2 минуты сайт: **https://simaklawyer.github.io/voennoe-pravo/**

Это не связано с основным сайтом по смыслу (отдельный репозиторий), только общий домен `github.io`. В поиске не должен появляться (`robots.txt` + `noindex`).

## Если «зависло» / кнопки не нажимаются

Чаще всего это **старый кэш service worker** на телефоне, а не сервер.

1. Chrome: настройки сайта → **«Удалить данные»** для этого адреса.
2. Или откройте в **режиме инкогнито**.
3. Если ставили как приложение — удалите иконку и добавьте снова.

## Локально

```bash
cd voennoe-pravo
python3 -m http.server 8080
# http://localhost:8080
```

## Структура

- `index.html` — оболочка
- `manifest.webmanifest` + `sw.js` — PWA / офлайн
- `js/app.js`, `js/pwa.js` — логика
- `css/` — темы (день / тёмная / ночь)
- `data/part1.json`, `data/part2.json` — материалы
