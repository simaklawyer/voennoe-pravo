# Военное право — шпаргалки

Локальный справочник по военному праву для быстрой работы с телефона.

## Что внутри

- **Оперативные шпаргалки**: снятие с воинского учёта, СОЧ / ст. 337, ВВК, рапорты, выплаты за ранение, дистанционное увольнение, семейные обстоятельства
- Модули курса (введение, законодательство, категории, выплаты, база знаний, стратегии)
- Поиск по заголовкам, тегам и тексту
- Темы: светлая / тёмная / **ночной режим** (тёплый, для чтения вечером)
- Навигация под телефон (нижняя панель + боковое меню)
- Размер шрифта в читалке сохраняется

## Как открыть локально

```bash
cd voennoe-pravo
python3 -m http.server 8080
# Откройте http://localhost:8080
```
